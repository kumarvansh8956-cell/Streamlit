# Streamlit Practice

A beginner-friendly repository for learning **Streamlit**, a Python framework for building interactive web applications.

## What I'm Learning
- Creating web interfaces using Python
- Interactive widgets and user inputs
- Displaying data and visualizations
- Building simple Python-based applications

## Tech Stack
- Python
- Streamlit

## Run Locally

```bash
pip install streamlit
streamlit run app.py
```

## Goal

Explore Streamlit and develop practical skills for building interactive applications and AI-powered web interfaces.
